# Depreciated Directory

All this code is no longer used. None of it is utilised for the development of results presented in the final report. However, it documents some of the original versions and initial attempts at tasks. Similarly, several files or functions were used in training, developing and comparing other models. 

Specifically, I tried to develop:

1. Segmentation Model 
2. CentreNet Model 
3. CentreNet with FPN backbone 
4. UNET++
5. Segmentation Model with Haussdoorf loss. 

Many other files show geostatistics, EDA (e.g. NDVI subdir) and development iterations of previous code (before large refactpring where I made a new file, maybe not best practice but it helps me stay focused).
